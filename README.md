# MyBlog

Goを勉強しながら作っている、シンプルなCRUDアプリです。
Goでバックエンドの流れを理解することを目的に、認証、記事管理、DB操作などを少しずつ実装しています。
勉強中で気づいたことを、動かして試しながら少しずつ修正しています。

## 使用しているもの

* Go
* Gin
* PostgreSQL
* JWT
* bcrypt
* Docker

## 主な機能

* ユーザー登録 / ログイン
* JWTによる認証
* ユーザープロフィール
* 記事の作成 / 編集 / 削除
* 記事一覧 / 詳細表示
* 記事検索
* ページネーション
* ユーザー / 管理者の権限管理

## テスト

`go test ./...` でテストを実行できます。

Service層を中心に、認証や記事操作、権限チェックなどのテストを書いています。

## 構成

```text
cmd/
internal/
├── handle/       # HTTPリクエストの処理
├── middleware/   # 認証・権限チェック
├── model/        # データモデル
├── repository/   # DBアクセス
├── router/       # ルーティング
└── service/      # アプリケーションの処理
templates/        # HTML
```
