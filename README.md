# MyBlog - Go言語で構築するブログシステム（練習用）

Go言語の標準ライブラリとSQLiteを活用した、軽量なブログシステムのバックエンドAPIです。
クリーンアーキテクチャの思想を取り入れ、拡張性と保守性を意識して開発しています。

---

## 概要
Go言語でのWebアプリケーション開発の実践、およびデータベース操作（CRUD）、セキュリティの基礎を習得することを目的として作成しました。

現在、データベースの初期化:テーブル作成、ユーザー登録のテストまで実装完了しています。

---

##　技術スタック

### Back-end
- **Language:** Go 1.26
- **Database:** SQLite (Pure Go サーバーレス構成)
- **External Packages:** 
  - `modernc.org/sqlite` (CgoレスのSQLiteドライバ)
  - `golang.org/x/crypto/bcrypt` (パスワードハッシュ化用)

---

## 問題点および学び

1. **セキュアなパスワード管理**
   - ユーザーの生パスワードはデータベースに直接保存せず、`bcrypt` アルゴリズムを用いて適切にハッシュ化（ソルト付与）してから保存しています。
2. **保守性の高いパッケージ構成**
   - ビジネスロジックとデータアクセス層を分離するため、**Repositoryパターン**を採用。`main.go` の肥大化を防ぎ、将来的なデータベースの変更（例：MySQLへの移行）にも柔軟に対応できる設計にしています。
3. **Cgoレスによるポータビリティの向上**
   - SQLiteのドライバに `modernc.org/sqlite` を採用することで、C言語のランタイム（Cgo）に依存しない純粋なGoコードのみでの構築を実現。環境依存のないスムーズなビルドが可能です。
